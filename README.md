# Prokopē

> **προκοπή** (grego): "progresso". Um pouco de progresso, todo dia.

App pessoal de hábitos, organizado em pilares e fases, para iPhone (instalado pela Tela de Início) e computador. Ainda em planejamento: o código começa pela etapa 0 do plano de desenvolvimento.
